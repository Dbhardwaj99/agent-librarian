# Knowledge Base

AI-maintained engineering wiki. Coding agents propose updates as events in `Stash/`; the Librarian audits them against source and folds them into these notes.

Each registered repository has its own hub at `<Project>/<Project>.md`. Start at the hub, then follow its links. Use the `search_memory` MCP tool or `librarian search` for direct lookup.

Writing and linking rules come from the `LIBRARIAN.md` shipped with Librarian. To customise them for this vault, add `Knowledge/LIBRARIAN.md`.
