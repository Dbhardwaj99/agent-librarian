# Knowledge Vault

Private memory for [agent-librarian](https://github.com/Dbhardwaj99/agent-librarian). Keep this repo private: it describes your codebases.

- `Knowledge/<Project>/` — canonical notes, edited only by the Librarian.
- `Knowledge/Stash/` — pending events from agents (one YAML file each).
- `Knowledge/librarian/daily-brief.md` — what the last Librarian run did.
- `agent-librarian.json` — registered repos and Librarian settings.

Useful commands: `agent-librarian add` (register a repo), `agent-librarian doctor`, `agent-librarian librarian --dry-run`.
