# Knowledge Vault

Private memory for [Librarian](https://github.com/Dbhardwaj99/librarian). Keep this repo private: it describes your codebases.

- `Knowledge/<Project>/` — canonical notes, edited only by the Librarian.
- `Knowledge/Stash/` — pending events from agents (one YAML file each).
- `Knowledge/librarian/daily-brief.md` — what the last Librarian run did.
- `librarian.json` — registered repos and Librarian settings.

Useful commands: `librarian add` (register a repo), `librarian doctor`, `librarian librarian --dry-run`.
